The browser has a feature that prevents web applications from manipulating eachother using their url. What happens here is that, if you want to connect your frontend to the backend, you can used the port that your backend is running on. However, because of this feature in the browser, it will not be possible it will prevent you from accessing a url that the client is not aware of. This feature promotes transparency. Rather, you have to define a proxy in vite.config.js file with a server:{proxy:{'/api':'http://localhost:3000'}}. This tells the browser that it is safe to access the specified api or url. and tell the client that your server is at this location and that you can access using this link.

The focus for this exercise in week8 is to test that your front and backend can communicated with eachother.
